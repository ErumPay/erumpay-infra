# ErumPay Litmus Chaos Infrastructure

This directory contains the Litmus Chaos Infrastructure manifest for the dev EKS cluster.

The manifest is generated from Litmus ChaosCenter and patched so the subscriber connects to the in-cluster GraphQL service:

```text
http://litmus-server-service.platform-operations.svc.cluster.local:9002/query
```

ArgoCD application:

```text
argocd/applications/litmus-chaos-infra-dev.yaml
```

Important:

- The ChaosCenter Helm application should install into `platform-operations`.
- The infrastructure manifest also installs into `platform-operations`.
- The subscriber secret contains the infrastructure access key generated by ChaosCenter. If the infrastructure is deleted and recreated in the UI, regenerate and replace `erumpay-chaos-infra.yaml`.
